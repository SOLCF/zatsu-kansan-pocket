# 雑換算ポケット

厳密さより「すぐ分かる目安」を優先する、生活換算の PWA（オフライン動作・外部通信なし）。

- 公開URL: https://solcf.github.io/zatsu-kansan-pocket/
- 仕様: [SPEC.md](SPEC.md) / 開発ルール: [CLAUDE.md](CLAUDE.md)

## 開発

ビルド不要。静的ファイルをそのまま配信します（`index.html` を静的サーバーで開く）。

```
npm test   # 換算関数の単体テスト（Node 標準の node --test）
```

## 現在の範囲

共通部品（計算型・対照表型・目安表示型）、マイ基準値、お気に入り、ジャンルの折り畳み、画面の色（ライト・ダーク）、キッチン4項目（米・乾麺・電子レンジ・計量）、日用品2項目（モバイルバッテリー・電池）、住まい3項目（エアコン・壁紙・塗料・部屋面積）、お金2項目（収入・燃料費・割り勘）、移動・地図2項目（徒歩・緯度経度とkm）、工作・趣味2項目（フィラメント・縮尺）、カメラ2項目（露出・星の流れ）、天気・自然6項目（標高差・風速・降水量・雨水量・体感・雲底高度と湿度）、日付3項目（西暦⇄和暦・日数計算・年齢）。SPEC の全16項目と、あとから追加した「Claude」ジャンル（文章量とトークン・トークンと料金・1回の呼び出しの料金・画像のトークン）に対応。
