# 雑換算ポケット

厳密さより「すぐ分かる目安」を優先する、生活換算の PWA（オフライン動作・キャッシュ優先。通信は設定画面の「更新」で版を確認するときだけ）。

- 公開URL: https://solcf.github.io/zatsu-kansan-pocket/
- 仕様: [SPEC.md](SPEC.md) / 開発ルール: [CLAUDE.md](CLAUDE.md)

## 開発

ビルド不要。静的ファイルをそのまま配信します（`index.html` を静的サーバーで開く）。

```
npm test   # 換算関数の単体テスト（Node 標準の node --test）
```

## 現在の範囲

SPEC.md の10ジャンル30項目すべてに対応。

- 共通部品: 計算型・対照表型・目安表示型
- 共通機能: マイ基準値、検索、お気に入り、ジャンルの折り畳み、画面の色（端末に合わせる・ライト・ダーク）、オフライン動作、設定画面の版表示・「更新」ボタン・GitHub へのリンク

| ジャンル | 項目 |
| --- | --- |
| キッチン | 米、乾麺、電子レンジ、計量 |
| 日用品 | モバイルバッテリー、電池 |
| 住まい | エアコン、壁紙・塗料、部屋面積 |
| お金 | 収入、燃料費・割り勘 |
| 移動・地図 | 徒歩、緯度経度と縮尺 |
| 工作・趣味 | フィラメント、縮尺 |
| カメラ | 露出（明るさ）、星の流れ |
| 天気・自然 | 標高差、風速、降水量、雨水量、体感（不快指数）、雲底高度と湿度 |
| 日付 | 西暦⇄和暦、日数計算、年齢（厄年の目安つき） |
| Claude | 文章量とトークン、トークンと料金、1回の呼び出しの料金、画像のトークン |
